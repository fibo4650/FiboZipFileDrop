# 📜 Fibo Zip File Drop (FZFD) — Human User & Workflow Guide

## 1. Executive Overview & Mission

**Fibo Zip File Drop (FZFD)** is a desktop Chrome Extension (Manifest V3) designed to eliminate file placement friction between AI chat environments (ChatGPT, Claude, Gemini, DeepSeek, Cursor) and your local project repositories.

When AI models generate multi-file code updates, they output flat ZIP archives, multiple individual code files, or raw code blocks containing destination path headers. Manually navigating folder trees, creating missing nested directories, and copying/pasting files slows down velocity. 

FZFD automates directory navigation, file creation, header comment extraction, and execution auditing using the native browser **File System Access API**.

---

## 2. Core Concepts & Features

### 🔌 Workspace Binding
* Connect your local project folder once with native read/write permissions.
* The system remembers your session during browser use and allows 1-click switching to a different project directory at any time without reloading the page.

### 📥 3 Ingestion Modes
1. **📦 File / ZIP Mode:** Drag & drop a `.zip` archive or multi-file selection onto the sidebar dropzone, or click to browse local files.
2. **📝 Raw Text Mode:** Paste a generated code snippet directly into a text area buffer for immediate header inspection and file staging.
3. **💬 Prompt Manager Mode:** Store, edit, search, and quick-copy prompt directives and variants (e.g., system instructions for code headers, MV3 checklist constraints) to feed back to your AI assistant.

### 🔍 Interactive Staging Review Matrix
Files are **never** written directly to disk without your approval. Every batch enters an in-memory review matrix:
* **File Status Badges:** Clear visual indicators (`NEW`, `main`, etc.) indicating whether a file is a brand new creation or lands in the workspace root.
* **Collision Detection & Overwrite Confirmation:** Existing local files require explicit checkbox confirmation to prevent accidental overwrites.
* **Master Toggle & Real-time Search:** Filter staged files by path substring and toggle overwrite checkboxes across visible files in one click.
* **Change-Type Dropdown:** Select custom commit behaviors for each file: `new`, `updated`, `replaced`, `append` (appends content to existing disk content while preserving headers), `prepend` (prepends content), or `delete` (removes the file from disk).
* **Inline Path & Header Editing:** Click any staged file path to inline-edit its target relative path or its Line 1, Line 2, and Line 3 header comments prior to writing.

### 📊 Automated Auditing & Logging
* **Auto-Log (`/FZFDlog`):** Human-readable execution run blocks appended to rotating log files inside your workspace root (`/FZFDlog/fzfd-YYYY-MM.log`).
* **Event JSON (`/events`):** Machine-readable structured JSON event batches emitted directly into `/events/extension-TIMESTAMP.json` for consumption by meta-framework tracking engines or post-delivery reconciliation scripts.

## 3. The 3-Line AI Header Comment Standard

To enable full path routing, chat session traceability, and feature tracking, instruct your AI coding assistant to prepend a **3-line comment header** to every generated file:

```javascript
// src/components/UserProfile.jsx
// Claude Sonnet 3.7 | User Profile Redesign | 2026-07-28
// feature: phase4-user-profile-card
```

### Line Breakdown
* **Line 1 (Target Path Directive):** Relative path enclosed in standard language comments (`//`, `#`, `/*`, `<!--`). MUST terminate with a valid file extension (e.g. `.js`, `.ts`, `.py`, `.md`, `.sql`) and MUST NOT contain URL protocols (`://`).
* **Line 2 (Session Provenance Stamp):** Formatted as `Model | Chat Session Name | YYYY-MM-DD`. FZFD extracts these details for log entries and event JSON tracking.
* **Line 3 (Feature Directive):** Formatted as `feature: <feature_id>`. Used to tie code deliveries directly to project management features or roadmap modules.

## 4. Step-by-Step User Workflow

```
[ 1. Left-Click 'F' Icon ] ──► [ 2. Connect Local Dir ] ──► [ 3. Drop ZIP / Drop Files / Paste Text ]
                                                                      │
[ 6. Download Run Log ] ◄── [ 5. Click 🚀 Send & Process ] ◄── [ 4. Review Matrix & Confirm Checks ]
```

### Step 1: Open the Extension Sidebar
Click the extension toolbar icon (**F**) on any website tab. An isolated sidebar slides open from the right edge of the screen.

### Step 2: Connect Your Project Workspace
1. Click **📁 Connect Local Dir** at the top of the sidebar.
2. Choose your local project root directory in the OS directory picker.
3. Grant read/write permissions when prompted by Chrome.
4. The status bar displays `Folder: <your-folder-name>`. You can click this button again at any point to switch project roots.

### Step 3: Ingest Code Artifacts
* **From a ZIP File:** Drag a ZIP file generated by an AI platform or sandbox onto the dropzone. FZFD unpacks the ZIP in memory, evaluates Line 1 path directives, falls back to internal archive relative paths if Line 1 is absent, and detects existing disk collisions.
* **From Dropped Files:** Drag multiple individual source files onto the dropzone.
* **From Clipboard / Text:** Select the **📝 Text** tab, paste your snippet, and click **⚡ Analyze Raw Text**. (Note: Raw text mode requires a valid Line 1 path comment directive).

### Step 4: Review and Adjust the Staging Matrix
1. Inspect the staged files list.
2. For files marked with an overwrite checkbox, review whether you want to replace local disk contents.
3. Optionally adjust the `change_type` dropdown for any file (`new`, `updated`, `replaced`, `append`, `prepend`, `delete`).
4. To edit a target path or modify comment headers, click the file path text to open the inline edit panel, make changes, and click **Save Changes**.

### Step 5: Execute Commit to Disk
1. Click **🚀 Send & Process**.
2. Watch the real-time progress bar write nested subfolders recursively and stream file contents.
3. Upon completion, a summary report appears displaying success and failure counts, alongside `/FZFDlog` and `/events` write confirmations.
4. Click **📥 Download Execution Log** if you wish to keep an immediate local text file summary of the commit.

---

## 5. Using the Built-In Prompt Manager

1. Click the **💬 Prompts** tab in the top navigation bar.
2. Browse saved system prompts or filter by favorites using the ⭐ button.
3. Use the search bar to filter prompt directives instantly.
4. Click **📋** on any prompt or variant card to copy its full rendered text directly to your clipboard.
5. Click **➕ Create New Prompt** or click an existing prompt title to edit prompt content or attach specialized **Variants** (e.g., `append` variants that append extra constraints, or `edit` variants that override the prompt entirely).

## 6. Frequently Asked Questions & Backend Logic Details

#### Q: How does FZFD handle nested subdirectories?
FZFD uses sequential recursive folder navigation through the File System Access API. If `src/components/auth/` does not exist on disk, FZFD creates `src/`, then `components/`, then `auth/` before opening a writable handle for the file stream.

#### Q: What happens when appending or prepending to a file?
When `append` or `prepend` change types are selected, FZFD reads the existing file from disk, strips and normalizes 3-line comment headers, merges the body sections cleanly with double line-breaks (`\n\n`), and writes the consolidated content back to disk.

#### Q: Are my local files sent to any external server?
**No.** FZFD operates 100% client-side inside your browser. All file reading, ZIP parsing, header extracting, and disk writing occur locally via the browser runtime and File System Access API. Zero data leaves your computer.
